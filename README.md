# 📊 Sleep Patterns and GPA Analysis

This project explores the relationship between students' sleep habits and academic performance using Python for data analysis and visualization. The goal is to identify whether sleep-related factors influence students' Grade Point Average (GPA).

## 📌 Project Overview

This project performs an exploratory data analysis (EDA) on a student sleep dataset by examining:

- GPA distribution
- GPA differences by gender
- Relationship between sleep duration and GPA
- Relationship between bedtime variability and GPA
- Correlation between numerical variables

The analysis is conducted using Python libraries such as Pandas, Matplotlib, and Seaborn.

---

## 📂 Dataset

The dataset contains information about students' academic performance and sleep patterns, including:

- Gender
- Average sleep hours
- Average sleep minutes
- Daytime sleep
- Bedtime variability
- Prior GPA
- Term GPA
- GPA change
- Study level
- Sleep tracking information

## 📈 Visualizations

The project includes several visualizations:

- Scatter Plot of Bedtime Variability vs GPA
- Correlation Heatmap

---

## 🔍 Key Insights

- Most students have a GPA between **3.2 and 4.0**.
- Male and female students show very similar GPA distributions.
- Average sleep duration has a **weak positive relationship** with GPA.
- Prior GPA is the strongest predictor of current academic performance.
- Bedtime variability has little impact on GPA.
- Students sleeping fewer than six hours tend to have slightly lower GPAs.

## 🎯 Conclusion

This analysis suggests that while healthy sleep habits may have a small positive association with academic performance, previous academic achievement is a much stronger predictor of GPA. Sleep alone does not fully explain variations in student performance.
